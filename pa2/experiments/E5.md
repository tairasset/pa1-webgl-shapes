# E5 — Frame-rate independence

Student ID 242458. Baseline: Codex in-app browser. CPU throttling and real
tab switching: native Microsoft Edge. These observations do not replace the
assignment's separate requirement to test in current Chrome or Firefox.

## Prediction

Accumulating timestamp differences rather than a fixed step per frame should
produce a 14-second orbit, within the next rendered frame. The 0.1-second
clamp deliberately discards excess time from longer stalls. Removing it should
produce a sudden pose change when frames resume after tab hiding.

## Explanation

The first timestamp establishes the time origin. Subsequent raw timestamp
differences are sampled for five seconds; the result records any overshoot
to the next frame. The orbit check ends on the first frame where t reaches
14 seconds. Both tested foreground runs overshoot by less than their final
frame interval. Their dt samples stay below the clamp.

CPU 4× slows JavaScript execution, not necessarily display refresh: this
small scene still sustained roughly 60 FPS. The test verifies the enabled
throttle and elapsed orbit time; it does not claim a fourfold FPS reduction.
If frame intervals exceeded 0.1 s, the clamp would discard elapsed time and
the orbit would take longer in wall time. Independence therefore holds within
that explicit limit, not under arbitrary long stalls.

Hidden-tab animation frames stopped in the observed run. Without the clamp,
the first timestamp difference includes the hidden interval. With the clamp,
the same large interval would contribute only 0.1 s, reducing the visible
jump while intentionally losing background elapsed time.

## Reproduction

Serve the repository locally. Measurements start on loading timing-clamped/
or timing-unclamped/; B restarts them when the keyboard produces Latin B.
Wait at least 15 s in the foreground for dt and orbit results. For throttling,
select 4× or 6× CPU in DevTools Performance before reloading. For tab return,
restore normal CPU speed, load the unclamped copy, switch tabs for about 5 s,
then save the returned status, visibility log and long-frame log.

These are isolated experiment copies; the main scene retains its clamp.
